# Fiscal AI Knowledge System

Le dossier knowledge constitue la mémoire officielle du projet.

Il contient :

- la gouvernance
- les décisions
- les connaissances métier
- les raisonnements
- les transformations
- les standards
- les prompts
- les architectures
- les observations

Le code n'est pas la seule source de vérité.

Le Knowledge System est versionné au même titre que le code.

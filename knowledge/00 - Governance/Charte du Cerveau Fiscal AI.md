# Mission

Obsidian est la source unique de vérité de Fiscal AI.

Son objectif est de fournir à Claude Code toutes les décisions d'architecture, de métier et de conception nécessaires afin de développer Fiscal AI avec un minimum d'ambiguïté, d'hallucinations et de régressions.

---

# Les 11 règles du Cerveau Fiscal AI

## 1. Source de vérité

Toute décision validée doit être documentée dans Obsidian.

Ce qui n'est pas dans Obsidian est considéré comme non décidé.

---

## 2. Destinataires

Le cerveau est écrit en priorité pour :

1. Claude Code
    
2. Les concepteurs du produit
    
3. Les futurs développeurs
    

---

## 3. Ce que nous documentons

Nous documentons uniquement :

- les décisions d'architecture ;
    
- les contraintes métier ;
    
- les contrats entre composants ;
    
- les comportements attendus.
    

Nous ne documentons pas ce que l'IA sait déjà faire.

---

## 4. Granularité

Une note représente un seul concept.

Une responsabilité.

Une décision.

---

## 5. Hiérarchie

En cas de contradiction :

Vision

↓

PRD

↓

Feature

↓

Scénario

↓

Blueprint

↓

SAS

↓

Code

Le niveau supérieur fait toujours autorité.

---

## 6. Évolution

Une note n'est modifiée que lorsqu'une décision est prise.

Jamais pendant une simple réflexion.

---

## 7. Périmètre

Nous documentons exclusivement le MVP.

Les fonctionnalités futures attendront d'entrer dans le périmètre du produit.

---

## 8. Niveau de détail

Nous nous arrêtons avant le code.

Le SAS prend ensuite le relais.

---

## 9. Amélioration continue

Une note peut évoluer lorsqu'une meilleure décision est validée.

Nous ne recherchons pas la perfection initiale.

Nous recherchons la meilleure version connue à un instant donné.

---

## 10. Objectif

Si Claude Code ne disposait que d'Obsidian, il devrait être capable de reconstruire Fiscal AI sans devoir inventer les décisions essentielles.

---

## 11. Gouvernance

Obsidian est l'autorité.

Les propositions de Claude Code, Cursor ou d'autres IA sont toujours les bienvenues.

Elles sont analysées.

Mais aucune ne devient une vérité tant qu'elle n'a pas été validée et intégrée dans Obsidian.

# Context Budget

Objectif : réduire la consommation de contexte et de tokens.

## Commencer petit

Lire d'abord :

- fichiers explicitement mentionnés ;
- tests associés ;
- imports directs pertinents.

## Élargir progressivement

N'ouvrir une dépendance supplémentaire que si elle est nécessaire pour répondre à une question identifiée.

## Interdit par défaut

- exploration exhaustive du repository ;
- lecture complète du Vault (`knowledge/`) ;
- ouverture de dizaines de fichiers « pour comprendre » ;
- relecture répétée des mêmes fichiers ;
- chargement de tous les Skills ;
- audit global lorsqu'un chantier local est demandé.

## Principe

Préférer 5 fichiers pertinents à 100 fichiers potentiellement intéressants.

## Stop condition

Si le chantier commence à nécessiter une exploration beaucoup plus large que prévu : STOP.

Résumer : ce qui est établi, ce qui manque, pourquoi le périmètre doit être élargi. Attendre confirmation si l'élargissement est substantiel.
